1. Basic Network Tools  
   - ping target.com  
   - dig target.com  
   - nslookup target.com  

2. DNS Reconnaissance  
   - dnsrecon -d target.com  
   - dnslookup  

3. Service and SSL Analysis  
   - whatweb  
   - nmap --script ssl-cert -p 443 <IP>  
   - shodan search ssl.cert.subject.CN:"domain" 200 --fields ip_str | httpx -sc -title -server -td

   - wafw00f url  

5. Advanced Reconnaissance Tools and Services  
   - Shodan: ssl.cert.subject.CN:"domain" 200  
   - Censys.io  
   - Fofa.so

6. Favicon Hash Identification  
   - Extract and analyze the favicon hash (use tools like hashcat or fav-up).

   - https://viewdns.info/reverseip/ (domain/IP)  
   - Netcraft: https://netcraft.com  

8. Security Headers Check  
   - https://securityheaders.com  

9. Other Reconnaissance Platforms  
   - ZoomEye: https://www.zoomeye.org  
   - VirusTotal: https://virustotal.com

    - whois target.com
